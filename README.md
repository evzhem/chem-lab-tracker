# ChemLab Tracker

Приложение-справочник по химии для телефона: реакции, таблица Менделеева, растворимость,
молярная масса, справочные схемы и дневник лабораторных опытов.

Работает и как сайт (PWA), и как Android-приложение (APK). Все данные хранятся на устройстве.

## Разделы

| Раздел | Содержание |
|--------|------------|
| **Реакции** | Поиск уравнений по веществам и подсказки-примеры |
| **Таблица** | Таблица Менделеева (118 элементов) + карточка элемента |
| **Растворимость** | Таблица с ориентировочными значениями г/100 мл H₂O |
| **Молярная масса** | Формулы, гидраты, скобки, расчёт растворов |
| **Схемы** | Ряды активности и электроотрицательности, потенциалы, кислоты, ТБ |
| **Дневник** | Опыты: цель, реактивы, шаги, наблюдения, статус |
| **Настройки** (⚙ в шапке) | Тема, проверка обновлений, данные дневника |

Таблицы Менделеева и растворимости — с одинаковыми ячейками, масштабом `− / + / ⤢ / сброс`
и закреплёнными заголовками; кнопка `⤢` умещает таблицу по ширине экрана.

## Технологии

- React + Vite, Tailwind CSS, lucide-react
- HashRouter, база `/chem-lab-tracker/` (GitHub Pages)
- Данные — локальные модули в `src/data`, состояние — `localStorage`
- PWA: `vite-plugin-pwa` (офлайн-режим, установка из браузера)
- Android: Capacitor

## Как работают обновления

1. Версия приложения хранится в `package.json`, история изменений — в `src/data/changelog.js`.
2. При сборке создаётся файл `version.json` (версия, номер сборки, список изменений, ссылка на APK).
3. При запуске приложение тихо запрашивает `version.json` и сравнивает версии.
4. Если версия на сервере новее — на главном экране появляется карточка обновления,
   а также окно с описанием изменений и кнопками **«Позже»** и **«Обновить»**:
   веб-версия обновляется автоматически, на Android открывается загрузка нового APK.

Выпуск обновления: поднять версию в `package.json`, добавить запись в `src/data/changelog.js`,
отправить изменения в `main` — сайт и APK пересобираются автоматически.

## Локальный запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка веб-версии в dist/
npm run preview  # просмотр собранной версии
```

Сборка веб-части под Android:

```bash
npm run build:apk-web   # сборка с base './'
npx cap sync android    # обновить нативную часть
```
